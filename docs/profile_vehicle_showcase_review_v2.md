## 4. Simplification Pass Architecture

Both screens implement the approved visual simplification:
1. **Automotive Photography as the Hero:** High-contrast editorial photography leads both screens without heavy competing badges or distracting graph overlays.
2. **Restrained Editorial Typography:** Clean Ice White (`#F4F6F2`) headlines with Titanium (`#A0AAB4`) secondary labels and Void Black (`#0A0D10`) backgrounds.
3. **Controlled Accent Application:** Performance Lime (`#C7F36B`) is reserved for primary CTAs (`Explore Full Showcase`, `View Full Build Timeline`), live build indicators, and active navigation states.
4. **Progressive Disclosure:** Deep build sheets (14 items), full chronological modification logs, and additional garage vehicles are accessible via secondary routes, keeping the primary viewport uncluttered.
